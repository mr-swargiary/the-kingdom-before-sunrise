01 / START HERE

The Questions Beginners Usually Have

There is no shame in being a beginner. Every expert once stared at a terminal wondering why the computer was apparently speaking another language.

What is The Kingdom Before Sunrise?

The Kingdom Before Sunrise is a cybersecurity learning platform designed to organize the journey from computer fundamentals to advanced cybersecurity concepts and professional career paths.

Where should a complete beginner start?

Start with computer fundamentals, then move through Linux, networking and programming before going deeper into cybersecurity.

The recommended order is: Fundamentals → Linux → Networking → Programming → Web → Cybersecurity → Specialization.

Do I need programming knowledge before learning cybersecurity?

No. You can begin cybersecurity without being an experienced programmer.

However, learning programming gradually becomes extremely useful for automation, analysis, scripting and understanding software.

Is Linux necessary for cybersecurity?

Linux is not the only operating system used in cybersecurity, but understanding Linux is highly valuable.

You should become comfortable with the terminal, files, permissions, processes, packages, services, SSH and logs.

Is cybersecurity only about hacking?

No. Cybersecurity includes defensive security, security operations, incident response, application security, cloud security, digital forensics, threat intelligence, security engineering and many other areas.

Authorized security testing is only one part of the field.

Can students learn cybersecurity?

Yes. Students can build a strong foundation by learning computers, Linux, networking, programming, problem solving and security concepts.

Practical activities should remain inside legal and authorized environments.

Do I need to be good at mathematics?

You do not need to be an advanced mathematician to begin learning cybersecurity.

Logical thinking, problem solving and understanding systems are important. Some specialized areas may require more mathematics than others.

02 / LEARNING

Learning The Right Way

How much should I study each day?

Consistency is usually more valuable than extremely long study sessions.

Even a focused session every day can build substantial knowledge over time.

Should I learn theory or practice first?

Use both.

Learn a concept, practice it in a safe environment, build something with it, then review what you learned.

A useful cycle is: Learn → Practice → Build → Document → Improve.

Should I learn many cybersecurity tools?

Do not make tool collecting your primary goal.

Understand the underlying concepts first. Tools change constantly, while fundamentals such as networking, operating systems and security principles remain useful.

How should I practice cybersecurity safely?

Use systems that you own, dedicated laboratories, educational platforms, authorized CTF environments or systems where you have explicit permission to test.

Never assume that a publicly accessible system is automatically available for testing.

Can I practice on random websites?

No. Public accessibility does not equal authorization.

Use intentionally vulnerable applications, authorized laboratories and systems where testing is explicitly permitted.

03 / CAREERS

Building A Cybersecurity Career

Which cybersecurity career should I choose?

There is no single best cybersecurity career for everyone.

Your choice should depend on your interests, strengths and the type of problems you enjoy solving.

For example, people interested in defense may explore SOC and security operations, while people interested in authorized testing may explore penetration testing or vulnerability assessment.

Are certifications required for cybersecurity jobs?

Requirements vary by employer and role. Some positions value certifications, while others place significant emphasis on education, practical skills, projects and experience.

Certifications should support your knowledge rather than replace it.

Do I need a college degree?

Requirements vary considerably between organizations and positions.

A degree can be useful for many career paths, while practical skills, projects, certifications and experience can also contribute to employability.

Always check the current requirements of the specific role you are interested in.

Does learning cybersecurity guarantee a job?

No.

Learning builds capability, but employment depends on many factors including skills, education, experience, portfolio quality, interview performance, opportunities and employer requirements.

How can I build a cybersecurity portfolio?

Build legitimate projects and document them clearly.

A strong project explanation can include the problem, objective, technologies, implementation, testing, lessons learned and future improvements.

04 / PROJECTS

Building Real Skills

What projects should a beginner build?

Start with small projects that strengthen programming and system knowledge.

Examples include a password generator, file organizer, system information tool, log reader, network calculator and hash calculator.

Should projects be complicated?

No. A well-understood small project is usually more valuable for learning than a huge project you cannot explain.

Increase complexity gradually as your skills improve.

Should I document my projects?

Yes.

Documentation demonstrates that you understand what you built, why you built it and what you learned.

06 / RESPONSIBILITY

One Rule Matters Most.

Learn cybersecurity deeply, but apply what you learn only where you have appropriate authorization.

Knowledge should make systems safer, not create unnecessary harm.
