CYBERSECURITY SKILL TREE

BUILD THE SKILLS.

Cybersecurity is built on layers of knowledge. Learn the fundamentals first, connect different technical disciplines, and gradually develop the skills required for your chosen security career.

Follow the Roadmap Explore Careers

HOW TO USE THIS PAGE

Think in Layers.

Do not try to learn everything at once. Cybersecurity contains a huge number of technologies, concepts, and specialties. Strong professionals usually build a broad foundation before going deep into a particular area.

PROGRESSION

From Beginner to Professional

01

Beginner

Understand computers, operating systems, files, networks, command lines, and basic programming concepts.

02

Intermediate

Build practical ability with Linux, networking, programming, web technologies, databases, and cybersecurity fundamentals.

03

Advanced

Develop specialization in defensive security, authorized security testing, cloud security, application security, forensics, or another professional area.

04

Professional

Combine technical knowledge, practical experience, communication, documentation, problem solving, and responsible security practices.

FOUNDATION 01

Computer Fundamentals

Before learning advanced security, understand the machines and operating systems you are trying to protect.

Hardware

CPU, RAM, storage, motherboard, networking hardware, input/output devices, and basic computer architecture.

Operating Systems

Understand what operating systems do and how Windows, Linux, and other systems manage hardware and software.

Files & Filesystems

Files, directories, paths, extensions, permissions, storage, and filesystem concepts.

Processes

Understand running programs, processes, services, memory usage, and system resources.

Command Line

Learn how command-line interfaces allow users to interact with operating systems efficiently.

Troubleshooting

Learn to identify problems systematically instead of randomly changing settings and hoping technology develops sympathy.

FOUNDATION 02

Linux Skills

Linux is heavily used across servers, cloud systems, security tools, development environments, and cybersecurity laboratories.

Terminal

Navigate systems and perform tasks through command-line tools.

Files & Directories

Create, move, copy, rename, search, and manage files and directories.

Permissions

Understand users, groups, ownership, read, write, execute permissions, and permission management.

Processes & Services

Learn how programs and background services run and how system activity can be inspected.

Package Management

Understand software packages, repositories, updates, and dependency management.

Bash & Shell

Learn shell commands, variables, conditions, loops, scripts, pipes, and automation.

SSH

Understand secure remote administration and the concepts behind encrypted remote access.

Logs

Learn why system logs matter and how they can help troubleshoot and investigate events.

FOUNDATION 03

Networking Fundamentals

Security professionals need to understand how computers communicate before they can understand how communication can be protected or attacked.

IP Addresses

IPv4, IPv6, private addresses, public addresses, and the role of addressing in networks.

MAC Addresses

Understand hardware addressing and how devices identify themselves at the local network level.

Ports

Learn what network ports represent and how services use them.

TCP & UDP

Understand the differences between connection- oriented and connectionless transport.

DNS

Learn how domain names are translated into network addresses.

DHCP

Understand how devices can automatically receive network configuration information.

HTTP & HTTPS

Learn how web communication works and why encrypted HTTPS connections matter.

Routing & NAT

Understand how traffic moves between networks and how network address translation works.

Firewalls

Learn the basic purpose of traffic filtering and network access control.

VPN Concepts

Understand encrypted tunnels, remote access, and the purpose of VPN technologies.

OSI Model

Learn the conceptual layers used to understand network communication.

Subnetting

Develop the ability to understand network ranges, subnet masks, and address organization.

FOUNDATION 04

Programming & Automation

Programming helps cybersecurity professionals automate repetitive tasks, analyze information, understand software, and build useful tools.

Python

Variables, conditions, loops, functions, files, modules, data structures, exceptions, APIs, and automation.

Programming Logic

Learn algorithms, problem solving, debugging, logical reasoning, and structured thinking.

C Fundamentals

Understand basic programming concepts and develop a foundation for understanding lower-level software and memory concepts.

JavaScript

Understand browser-side programming and the fundamentals of modern web applications.

SQL

Learn databases, tables, queries, relationships, filtering, and structured data.

Bash

Automate command-line tasks and combine Linux utilities into useful scripts.

APIs

Understand how applications communicate and exchange structured information.

Automation

Turn repetitive workflows into reliable, repeatable processes.

FOUNDATION 05

Web Technologies

Modern applications are major components of the digital world. Understanding how they work is essential for application security.

HTML

Understand the structure and semantics of web pages.

CSS

Learn how web interfaces are styled, structured, and made responsive.

JavaScript

Understand client-side logic and interaction within web applications.

HTTP

Learn requests, responses, methods, headers, status codes, and web communication.

Cookies & Sessions

Understand how websites maintain state and recognize users between requests.

Authentication

Learn the concepts behind identity verification, passwords, sessions, and modern authentication.

APIs

Understand application interfaces and how different services communicate.

Databases

Learn how web applications store and retrieve structured information.

SECURITY 01

Cybersecurity Fundamentals

CIA Triad

Confidentiality, integrity, and availability form a fundamental model for understanding information security.

Threats

Understand different categories of threats that can affect systems and organizations.

Vulnerabilities

Learn what weaknesses are and why they can create security risk.

Risk

Understand the relationship between threats, vulnerabilities, likelihood, and impact.

Authentication

Understand how systems verify identity.

Authorization

Understand how systems determine what an authenticated user is allowed to do.

Encryption

Learn how cryptographic techniques can protect information from unauthorized access.

Hashing

Understand one-way transformations and common security uses for hashes.

Digital Signatures

Learn the concepts behind authenticity, integrity, and non-repudiation.

Malware Concepts

Understand malware categories and their security impact at a high level.

Social Engineering

Learn how manipulation and deception can be used to influence people and why awareness matters.

Security Architecture

Understand how multiple security controls work together to protect systems.

SPECIALIZATION 01

Defensive Security

Blue-team skills focus on detecting threats, protecting systems, investigating incidents, and improving defenses.

Log Analysis

Learn how security and system logs can reveal important events and patterns.

SIEM

Understand how Security Information and Event Management platforms collect and analyze events.

Security Monitoring

Learn how systems and networks can be monitored for suspicious activity.

Incident Response

Understand the lifecycle of identifying, containing, investigating, and recovering from security incidents.

Threat Intelligence

Study information about threats to improve defensive decision-making.

Endpoint Security

Understand how computers and other endpoints can be monitored and protected.

Detection Engineering

Learn the concepts behind creating useful detections for suspicious behavior.

Security Operations

Understand how security teams coordinate monitoring, investigation, response, and reporting.

SPECIALIZATION 02

Authorized Security Testing

Offensive-security knowledge can help identify weaknesses before malicious actors exploit them. Practice must always remain within systems and environments where you have explicit authorization.

Reconnaissance Concepts

Understand how security professionals gather information about authorized targets and define an assessment scope.

Enumeration

Learn how authorized assessments identify available services and technologies.

Vulnerability Assessment

Learn how potential weaknesses are identified, validated, documented, and prioritized.

Web Security

Study common web-security weaknesses using legal training environments and intentionally vulnerable applications.

Network Security Testing

Understand security assessment concepts for authorized network environments.

Reporting

Learn how professional security findings are documented with evidence, impact, and remediation recommendations.

Remediation

Understand how security findings can be fixed and how improvements can be verified.

Security Ethics

Learn the importance of authorization, scope, responsible disclosure, privacy, and professional conduct.

SPECIALIZATION 03

Cloud Security

Cloud Fundamentals

Understand cloud computing models, services, infrastructure, and shared-responsibility concepts.

Identity & Access

Learn identity management, permissions, authentication, and access control.

Cloud Networking

Understand virtual networks, segmentation, traffic controls, and secure connectivity.

Cloud Monitoring

Learn how cloud environments can generate security and operational events.

Data Protection

Understand the security principles used to protect cloud-hosted information.

Secure Architecture

Learn how security controls can be designed into cloud infrastructure.

SPECIALIZATION 04

Digital Forensics

Evidence Concepts

Understand why digital evidence must be handled carefully and documented properly.

Filesystems

Learn how operating systems organize and store digital information.

Disk Analysis

Understand the concepts involved in examining storage media during authorized investigations.

Memory Concepts

Learn why volatile memory can contain useful information during investigations.

Timeline Analysis

Understand how investigators reconstruct events from available digital evidence.

Reporting

Learn how technical findings can be documented clearly and objectively.

PROFESSIONAL DEVELOPMENT

Technical Skills Aren't Everything

A strong cybersecurity professional also needs communication, discipline, documentation, curiosity, and the ability to explain technical problems clearly.

Problem Solving

Break complicated problems into smaller, understandable parts.

Analytical Thinking

Compare evidence, recognize patterns, test assumptions, and reach logical conclusions.

Communication

Explain technical issues to both technical and non-technical people.

Documentation

Record processes, findings, decisions, and evidence clearly.

Research

Learn how to read documentation, investigate unfamiliar technologies, and verify information.

Continuous Learning

Technology changes constantly. Cybersecurity professionals need to keep learning throughout their careers.

LEARNING PRINCIPLES

Don't Chase Tools.

Tools change. Fundamentals remain useful.

Learn what a technology does, why it exists, what problem it solves, and how it works before trying to memorize a collection of commands.

Build knowledge first. Then use tools to apply that knowledge in authorized environments.

RESPONSIBLE SECURITY

Skills Come With Responsibility.

Security knowledge must be used responsibly. Never access, scan, test, disrupt, or modify systems without authorization.

Use your own systems, dedicated laboratories, legal CTF environments, intentionally vulnerable applications, or other environments where you have explicit permission.
